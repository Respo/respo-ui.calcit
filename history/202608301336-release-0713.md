# Release 0.7.13 / 发布 0.7.13

## 中文

- 发布 Respo UI 0.7.13，要求 Calcit CLI 与 `@calcit/procs` 0.13.64。
- 保持 0.7.12 的无循环 UI 依赖图、严格质量 baseline 与公共 UI API 不变。
- 通过 strict Caps、Calcit tests/type checks、JS 生成、immutable Yarn install 与 Vite build 验证。

## English

- Release Respo UI 0.7.13 with Calcit CLI and `@calcit/procs` 0.13.64 required.
- Keep the cycle-free UI dependency graph, strict quality baseline, and public UI API from 0.7.12 unchanged.
- Verify with strict Caps, Calcit tests/type checks, JS codegen, immutable Yarn install, and the Vite build.
