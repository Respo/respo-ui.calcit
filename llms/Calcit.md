# Calcit project reference

This module uses the canonical `calcit.cirru` snapshot and the current Calcit CLI.

Read maintained documentation when needed:

```bash
calcit docs agents --full
calcit docs read upgrade --full
calcit docs read edit-tree.md --full
calcit docs read static-analysis.md --full
```

Use `calcit` for query/edit/check/codegen commands. Do not use `cr` or document the retired `compact.cirru` workflow here. For Respo APIs, use:

```bash
calcit libs readme respo.calcit --file docs/Respo-Agent.md --full
```
